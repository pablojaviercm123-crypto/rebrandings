# Skills de importaciones · SILDEC

Tres skills para gestionar importaciones de SILDEC SRL en Excel. Se complementan con las skills que ya existen en la cuenta (`sildec-formato-excel`, `sildec-asesor-financiero`, `cronex-rotacion-90d`).

| Skill | Para qué sirve |
|---|---|
| `sildec-costeo-importacion` | Costo puesto en almacén por ITEM: incoterms, CIF, GA, IVA 14,94 % (crédito fiscal), prorrateo, TC BCB y precios A/B/C |
| `sildec-seguimiento-importaciones` | Tablero de la orden al ingreso a DeltaWin: etapas, pagos 30/70, alertas, caja en USD y lead time |
| `sildec-formulas-importacion` | Recetario de fórmulas compatibles (sin BUSCARX ni MAX.SI.CONJUNTO) y nivel moderno: tablas, Power Query, validación, controles |

## Instalar
En claude.ai: Configuración → Capacidades → Skills → subir el .zip de `dist/`.

Las tasas de aranceles e impuestos cambian: verificarlas siempre con la DIM y el despachante.
